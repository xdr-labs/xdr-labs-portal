Parser Studio helps security engineers turn representative device and security product logs into reviewed **Stellar Cyber 7.0 parser drafts** through a browser UI. You can inspect the extracted fields and mapping results before downloading parser files, without writing Ruby parsing rules from scratch.

## When to use it

Use Parser Studio when a security device or product emits logs that need a custom parser or clearer field mapping in Stellar Cyber. It is designed for firewall, IDS/IPS, WAF, VPN, endpoint, identity, network, and other security telemetry formats. Actual parsing success depends on each log's structure and the examples you provide.

## Two parser creation workflows

<CardGroup cols={2}>
  <Card title="Auto Parser" icon="wand-magic-sparkles">
    Paste or upload representative logs, analyze their structure, review extracted fields, map them to Stellar Cyber 7.0 fields, and create a parser draft when the checks pass.
  </Card>

  <Card title="ChatGPT Assisted Parser" icon="comments">
    When a log or mapping needs extra help, prepare a prompt, manually share an authorized and redacted sample with ChatGPT, then import and validate a structured suggestion. AI output is not automatically approved.
  </Card>
</CardGroup>

## From logs to parser files

<Steps>
  <Step title="Add representative logs">
    Provide complete sample events, including different event types from the same product where relevant.
  </Step>
  <Step title="Analyze and review">
    Examine detected structures, original field values, event boundaries, and any unparsed text.
  </Step>
  <Step title="Map fields">
    Review and adjust the mappings against the Stellar Cyber 7.0 field catalog. Uncertain mappings need your confirmation.
  </Step>
  <Step title="Create and download">
    When validation succeeds, download the matching Ruby parser logic and companion `.conf` file. An optional Python test sender can help with later lab verification.
  </Step>
</Steps>

## Supported review capabilities

- Format review for Syslog, JSON, CEF, LEEF, key/value, CSV, and supported mixed or multiline records.
- Visibility into partial matches and original unparsed spans instead of silently dropping them.
- Multiple log types from one product with shared field-mapping review.
- Browser-local working versions, sample checks, and artifact integrity checks.

<Warning>
  Parser Studio generates **reviewed parser drafts**, not automatically deployed production parsers. It does not upload or activate parsers on a Stellar Cyber Data Processor, and successful sample validation does not establish DP runtime compatibility. Verify the generated pair in a suitable Stellar Cyber 7.0 test environment before production use.
</Warning>

<Note>
  Clicking **Analyze Logs** submits the original samples to the Parser Studio server for analysis. It does **not** automatically send logs to ChatGPT. ChatGPT Assisted requires a separate manual copy step; redact sensitive values and obtain authorization before using customer logs.
</Note>
