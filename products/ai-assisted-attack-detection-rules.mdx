## Import into Stellar Cyber 7.0 (lab first)

1. **Back up the existing complete \`custom_defined.rules\`.** *Import Security Rules replaces the entire custom rules file* and can discard site-specific signatures.
2. Download the **full 383-rule file** from the link above, check its SHA-256, and merge any site-local rules as necessary.
3. Use \`System → Data Source Management → Sensors → Sensors → Manage → Import Security Rules\` on a **lab Sensor**.
4. Select the merged file and use \`Upload and Deploy\`, then check \`Sensor Profiles → IDS → Signature → Selected Rules\`, \`eve.json\` and DP Alerts.
5. Baseline normal traffic and tune lower-specificity indicators **before production**.

Unlike the previous 339, some new signatures use \`$HOME_NET\`, \`$EXTERNAL_NET\`, \`$HTTP_SERVERS\` or specific destination ports. Confirm IDS Networks settings and protected public IP ranges. HTTPS headers/bodies require plaintext or decrypted capture; QUIC, DoH and ECH may reduce visibility.

**Research and QA-backed signature pack only.** Do not interpret controlled PCAP passes as production-grade detection accuracy.
