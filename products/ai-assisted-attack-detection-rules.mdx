**AI-Assisted Attack Detection Rules** is a downloadable Suricata signature pack designed for evaluating web attacks, AI-assisted penetration-testing tools, and selected red-team activity in Stellar Cyber 7.0 test environments.

The pack contains **322 alert-only rules (v0.8)**. It uses `any any -> any any` headers, without requiring `HOME_NET` or `EXTERNAL_NET`. Request/response flow constraints remain in place where applicable.

## What it detects

- Common web attack patterns: SQL injection, command injection, path traversal, XSS, webshell activity, and executable uploads.
- Identifiable AI-assisted testing tool and scanner fingerprints, including ARTEX, CyberStrikeAI, HexStrike-AI, Nuclei, sqlmap, and other tools.
- Selected C2 and red-team network signatures, including Cobalt Strike, Havoc, and Meterpreter.
- Selected public ET Open exploit signatures for products and frameworks including PHP, Tomcat, Next.js, Fortinet, Citrix, Cisco ASA/FTD, Confluence, and Apache Struts2.

<Note>
  “AI-assisted” describes attack tools and patterns that can be identified by static network signatures. **This rule pack does not perform AI inference.** Tool User-Agents can be changed or spoofed.
</Note>

</Warning>

Most HTTP payload signatures require visible **plaintext or decrypted HTTP**. This pack supplements—not replaces—the sensor's built-in IDS/NDR detections. The small synthetic PCAP test set does not establish a production detection rate or false-positive rate.
