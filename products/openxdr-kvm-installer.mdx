# OpenXDR KVM Installer

OpenXDR KVM Installer is a script-based automation framework for preparing KVM hosts and deploying Stellar Cyber OpenXDR components. The dedicated documentation now lives at **[kvm.xdr.ooo](https://kvm.xdr.ooo/)**.

It uses interactive, menu-driven workflows with persistent state so operators can validate configuration in safe mode, execute the complete deployment or individual steps, reboot when required, and resume from the next incomplete step.

## Deployment paths

- **Data Processor (DP)** — DL-master / DA-master deployment with storage, networking, SR-IOV or bridge-based cluster networking, CPU placement, and NFS backup configuration
- **Standard Sensor** — modular Sensor deployment with NAT or bridge management networking and PCI or bridge SPAN attachment
- **High-Performance Sensor** — dual-VM / NUMA-oriented high-throughput Sensor deployment
- **AIO + Sensor** — integrated AIO Data Processor and Sensor deployment on one KVM host

## Safe deployment workflow

```text
Check hardware
  → Configure installer inputs with DRY_RUN enabled
  → Review the complete DRY_RUN flow
  → Run Full Configuration Validation
  → Resolve FAIL results and review WARN results
  → Re-check NIC, IP, disk, version, and credentials
  → Set DRY_RUN=0
  → Run all steps or a specific step
  → Reboot when required
  → Relaunch the same installer and resume
  → Perform post-deployment validation
```

<Warning>
  With `DRY_RUN=0`, the installer can modify networking, storage, kernel settings, virtualization configuration, and VM definitions. Ensure console or out-of-band access is available before changing remote host networking.
</Warning>

## Host platform

The primary documented installation path is **Ubuntu Server 24.04 LTS**. The installer source may retain compatibility paths for older Ubuntu/OpenXDR releases, but legacy deployments should verify the current implementation and target-release support rather than assuming the 24.04 procedure applies unchanged.
