# 공통 설계 철학

XDR Labs 프로젝트들은 서로 독립적이지만, 현장에서 실제로 운영하기 쉬운 도구를 만든다는 공통 원칙을 공유합니다.

<CardGroup cols={2}>
  <Card title="현장 문제부터 해결" icon="wrench">
    기능 수를 늘리기보다 실제 배포, 지원, 검증, 데이터 운영에서 반복되는 문제를 출발점으로 합니다.
  </Card>

  <Card title="반복 작업은 자동화" icon="gears">
    설치, 준비, 검증, 상태 관리처럼 사람이 반복하면서 실수하기 쉬운 작업을 자동화합니다.
  </Card>

  <Card title="프로젝트는 독립적으로" icon="boxes-stacked">
    하나의 프로젝트를 사용하기 위해 다른 프로젝트까지 설치할 필요는 없습니다. 소스 저장소와 릴리스 주기도 각각 독립적으로 관리합니다.
  </Card>

  <Card title="운영 경계를 문서화" icon="book-open">
    사전 조건, 책임 범위, 지원 경로, 실패 시 동작과 복구 방법을 사용자 문서에 명확하게 설명합니다.
  </Card>
</CardGroup>
