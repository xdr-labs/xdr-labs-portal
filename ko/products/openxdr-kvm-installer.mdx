# OpenXDR KVM Installer

OpenXDR KVM Installer는 KVM 호스트 준비와 Stellar Cyber OpenXDR 구성 요소 배포를 자동화하는 스크립트 기반 도구입니다. 자세한 설치·운영 문서는 \*\*[kvm.xdr.ooo](https://kvm.xdr.ooo/ko)\*\*에서 제공합니다.

대화형 메뉴와 작업 상태 저장 기능을 사용합니다. 먼저 안전 모드에서 설정을 검증하고, 전체 배포 또는 필요한 단계만 실행할 수 있으며, 재부팅 후에는 완료하지 못한 단계부터 이어서 진행할 수 있습니다.

## 배포 경로

- **Data Processor (DP)** — DL-master / DA-master, 스토리지, 네트워크, SR-IOV 또는 브리지 기반 클러스터 네트워크, CPU 배치, NFS 백업 구성
- **Standard Sensor** — NAT 또는 브리지 관리 네트워크와 PCI 또는 브리지 방식 SPAN 연결을 사용하는 Modular Sensor 배포
- **High-Performance Sensor** — 듀얼 VM / NUMA 기반 고성능 Sensor 배포
- **AIO + Sensor** — 하나의 KVM 호스트에 AIO Data Processor와 Sensor를 함께 배포

## 안전한 배포 흐름

```text
하드웨어 확인
  → DRY_RUN 상태에서 설치 입력값 설정
  → DRY_RUN으로 전체 흐름 점검
  → 전체 구성 검증
  → FAIL 해결 및 WARN 확인
  → NIC, IP, 디스크, 버전, 인증 정보 재확인
  → DRY_RUN=0 전환
  → 전체 단계 또는 필요한 단계만 실행
  → 필요한 시점에 재부팅
  → 같은 설치 프로그램을 다시 실행해 이어서 진행
  → 배포 후 검증
```

<Warning>
  `DRY_RUN=0`부터는 네트워크, 스토리지, 커널, 가상화 설정과 VM 정의가 실제로 변경될 수 있습니다. 원격 호스트의 네트워크를 변경하기 전에 콘솔 또는 Out-of-Band 접속 수단을 확보하십시오.
</Warning>

## 호스트 운영체제

현재 문서의 기본 설치 경로는 **Ubuntu Server 24.04 LTS**입니다. 설치 소스에는 이전 Ubuntu/OpenXDR 버전을 위한 호환 코드가 남아 있을 수 있지만, 기존 환경에 24.04 절차가 그대로 적용된다고 가정해서는 안 됩니다. 대상 버전과 현재 지원 범위를 먼저 확인하십시오.
