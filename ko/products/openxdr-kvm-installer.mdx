# OpenXDR KVM Installer

OpenXDR KVM Installer는 KVM Host를 준비하고 Stellar Cyber OpenXDR 구성 요소를 배포하기 위한 Script 기반 자동화 Framework입니다. 전용 문서는 **[kvm.xdr.ooo](https://kvm.xdr.ooo/ko)**에서 제공합니다.

Interactive Menu와 Persistent State를 사용하여 Safe Mode에서 설정을 검증하고, 전체 배포 또는 개별 Step을 실행하며, 필요한 Reboot 후 다음 미완료 Step부터 Resume할 수 있습니다.

## 배포 경로

- **Data Processor (DP)** — DL-master / DA-master, Storage, Network, SR-IOV 또는 Bridge 기반 Cluster Network, CPU Placement 및 NFS Backup 구성
- **Standard Sensor** — NAT 또는 Bridge Management Network와 PCI 또는 Bridge 방식 SPAN 연결을 사용하는 Modular Sensor 배포
- **High-Performance Sensor** — Dual VM / NUMA 기반 고성능 Sensor 배포
- **AIO + Sensor** — 하나의 KVM Host에 AIO Data Processor와 Sensor 통합 배포

## 안전한 배포 흐름

```text
Hardware 확인
  → DRY_RUN을 유지한 상태에서 Installer 입력값 구성
  → DRY_RUN으로 전체 흐름 점검
  → Full Configuration Validation
  → FAIL 해결 및 WARN 검토
  → NIC, IP, Disk, Version, Credential 재확인
  → DRY_RUN=0 전환
  → 전체 Step 또는 개별 Step 실행
  → 필요한 시점에 Reboot
  → 동일 Installer 재실행 후 Resume
  → 배포 후 Validation
```

<Warning>
  `DRY_RUN=0`부터는 Network, Storage, Kernel, Virtualization 설정과 VM 정의가 실제로 변경될 수 있습니다. 원격 Host의 Network를 변경하기 전에 Console 또는 Out-of-Band 접근을 확보하십시오.
</Warning>

## Host Platform

현재 문서의 기본 설치 경로는 **Ubuntu Server 24.04 LTS**입니다. Installer Source에는 이전 Ubuntu/OpenXDR Release용 Compatibility Path가 남아 있을 수 있지만, Legacy 배포는 24.04 절차가 그대로 적용된다고 가정하지 말고 현재 구현과 대상 Release 지원 범위를 확인해야 합니다.
