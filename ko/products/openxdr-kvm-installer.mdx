# OpenXDR KVM Installer

OpenXDR KVM Installer는 KVM Host를 준비하고 Stellar Cyber OpenXDR 구성 요소를 배포하는 과정을 자동화합니다. Interactive Menu와 상태 추적을 사용하여 설정을 검증하고 전체 배포를 수행하거나, 필요한 Reboot 후 이어서 실행할 수 있습니다.

## 배포 대상

- **Data Processor (DP)** — Standalone DP 배포
- **Sensor** — Standard Modular Sensor 배포
- **High-Performance Sensor** — Dual VM / NUMA 기반 고성능 Sensor 배포
- **AIO + Sensor** — 한 Host에 AIO Data Processor와 Sensor 통합 배포

## 기본 요구사항

지원 Host OS는 Installer에 따라 다릅니다. 현재 Sensor/AIO 경로는 Ubuntu Server 20.04, 22.04, 24.04를 사용하며 일부 DP Workflow는 Ubuntu 16.04도 지원합니다. Root 권한과 Hardware Virtualization이 필요하며 SR-IOV/PCI Passthrough를 사용하는 경우 BIOS에서 IOMMU가 활성화되어야 합니다. Package와 Stellar Component Image 다운로드를 위해 일반적으로 Internet Access도 필요합니다.
