## Stellar Cyber 7.0 적용 방법

1. Sensor의 기존 **\`custom_defined.rules\` 전체를 먼저 백업**합니다. *Import Security Rules는 파일 전체를 교체*하므로 기존 현장 룰을 잃지 않도록 주의하세요.
2. 통합 **383개 .rules** 파일을 다운로드해 SHA-256을 검증하고 현장 고유 룰과 병합 여부를 확인합니다.
3. **테스트용 Modular Sensor**의 \`System → Data Source Management → Sensors → Sensors → Manage → Import Security Rules\` 메뉴에서 전체 파일을 선택합니다.
4. 실험 환경에서 \`Upload and Deploy\` 후 \`Sensor Profiles → IDS → Signature → Selected Rules\`, Sensor \`eve.json\`, DP Alert 등을 검증합니다.
5. **일반적인 도구 사용과 겹치는 탐지 지표**를 정상 트래픽으로 검증·튜닝한 뒤 운영 적용을 판단합니다.

신규 44개에는 \`$HOME_NET\`, \`$EXTERNAL_NET\`, \`$HTTP_SERVERS\` 및 특정 포트 조건이 포함돼 기존 339개와 달리 IDS Networks 설정이 탐지에 영향을 줄 수 있습니다. HTTPS 헤더/본문은 평문 또는 복호화 데이터가 필요하며 QUIC/DoH/ECH 환경에서는 가시성이 제한됩니다.

**본 패키지는 연구·QA 검증용 공개 룰셋으로 실운영 탐지 성능을 보증하지 않습니다.** 기존 2개 SID의 미해결 오탐·미탐 위험도 남아 있습니다.
