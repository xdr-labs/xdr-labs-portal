## 탐지 범위

- **기본 웹 공격:** SQL Injection, Command Injection, Path Traversal, XSS, 웹셸, 실행 파일 업로드
- **AI 지원 모의해킹·Red Team 도구:** ARTEX, CyberStrikeAI, HexStrike-AI, Cobalt Strike, Havoc 등의 일부 식별 가능한 특징
- **v0.9 신규 11개:** /dev/tcp 리버스셸 문자열, 인코딩된 명령 구분자, AntSword·China Chopper 지문, Interactsh·Burp Collaborator OAST DNS 조회

모든 룰은 alert 전용이고 주소·포트 조건은 any any → any any입니다. **룰 자체에 AI 모델이 포함된 것은 아닙니다.**

### 실제 탐지한 신규 룰 11개

| SID | 테스트한 네트워크 패턴 |
| --- | --- |
| `9006001` / `9006002` | HTTP URI / POST 본문의 `/dev/tcp` 리버스셸 문자열 |
| `9006009` | 인코딩된 줄바꿈 뒤 OS 명령 (`%0a`) |
| `9006010` | AntSword User-Agent |
| `9006011` | PHP 웹셸 관리 패턴 (`ini_set` + `set_time_limit`) |
| `9006071` / `9006072` | 인코딩된 명령 구분자 및 셸 명령 치환 |
| `9006064`–`9006067` | Interactsh·Burp Collaborator OAST DNS 조회 |

**기본 IDS와 구분:** 유사 DNS 도메인 `notburpcollaborator.net`에 기본 ET SID `2034825`가 경고했습니다. 이는 **v0.9 신규 룰의 경고가 아닌 기존 ET 룰의 경고**입니다. 기본 `exploit.rules`의 ETPRO 2개(SID `2868495`, `2868498`)는 센서에서 `krb5`·`nfs` 프로토콜이 비활성화되어 로딩에 실패했지만, **v0.9의 333개 커스텀 룰 로딩 오류는 0개**입니다. 기존 ETPRO 룰과 센서 설정은 변경하지 않았습니다.

이 PoC는 **제작한 평문 HTTP/DNS 탐지 패턴 11종에 대한 실제 센서 IDS 검증**입니다. 실제 공격 성공 여부, 암호화 트래픽 탐지, 운영망 오탐률, Stellar Cyber DP/UI Alert 전달까지 입증하는 것은 아닙니다.

<Warning>
  **실제 센서 PoC를 통과한 검증본이지만, 운영환경 탐지 성능을 보장하지 않습니다.** Import 전 기존 custom_defined.rules를 반드시 백업하세요. 센서 버전과 기본 ET 룰 중복을 확인하고, DP/UI Alert 생성은 별도로 검증해야 합니다.
</Warning>

**검증 한계:** AD 공격(DCSync, PetitPotam, PsExec, Kerberoasting) 신규 룰은 정상 관리 트래픽과 구별하는 검증이 부족해 이번 버전에서 제외했습니다. 기존 v0.8의 XSS 룰은 정상 HTML 예시에도 경고할 수 있으며, OAST DNS는 승인된 모의해킹에서도 나타납니다. HTTPS 페이로드 검사는 평문 트래픽 또는 외부 복호화가 필요합니다.
