# 프로젝트 관계 및 디렉터리

## 프로젝트 관계 한눈에 보기

```mermaid
flowchart TD
    P[xdr.ooo\nXDR Labs 통합 포털]

    subgraph INFRA[Infrastructure & Operations]
      KVM[OpenXDR KVM Installer\nDP / Sensor / AIO 배포]
      UPG[DP Upgrade Mirror Manager\nUbuntu + DP 업그레이드]
      CLI[Stellar Appliance CLI\nKVM Appliance 운영]
      FRP[FRP Auto Deploy\nNAT 뒤 원격 접속]
    end

    subgraph LAB[Lab & Detection Validation]
      XLAB[XDR Lab Appliance\n반복 가능한 Lab 구성]
      DSP[Detection Scenario Platform\n시나리오 트래픽 생성]
    end

    subgraph DATA[Data & Integration]
      DR[Data Relay\n데이터 통제 및 전달]
      SYS[Stellar Alert & Case Relay\nAlert / Case 전달]
    end

    P --> KVM
    P --> UPG
    P --> CLI
    P --> FRP
    P --> XLAB
    P --> DSP
    P --> DR
    P --> SYS

    KVM --> CLI
    XLAB --> DSP
```

이 구조는 **하나로 묶인 거대한 Platform이 아니라 독립적으로 사용할 수 있는 Toolbox**입니다. 화살표는 함께 쓰기 좋은 일반적인 관계를 보여줄 뿐, 필수 의존성을 의미하지 않습니다.
