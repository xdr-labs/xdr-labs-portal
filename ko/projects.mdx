# 프로젝트 소개

각 프로젝트는 독립적으로 사용할 수 있으며, 필요한 기능만 선택해서 배포할 수 있습니다.

<Note>
  **Data Relay Link와 Data Relay Control은 서로 다른 제품입니다.** Data Relay Link는 Private System으로의 Secure Remote Access와 제한망에서의 Controlled Egress를 담당합니다. Data Relay Control은 Enterprise Data Flow의 Processing, Governance 및 Delivery를 담당하며 Link의 중앙 관리 제품이 아닙니다.
</Note>

## 핵심 프로젝트

<CardGroup cols={2}>
  <Card title="Data Relay Link" icon="network-wired" href="https://link.datarelay.run/">
    소규모 환경을 위한 Lightweight Secure Connectivity Gateway입니다. NAT/방화벽 뒤 시스템에서 필요한 SSH, HTTP, HTTPS, Custom TCP 서비스만 선택해 공개하고, 제한망 Host가 승인된 Internet Destination만 접근하도록 Agentless HTTP/HTTPS Proxy 기반 Controlled Egress도 제공합니다.

    **제품:** `link.datarelay.run`  
    **소스:** `datarelay-labs/data-relay-link`
  </Card>

  <Card title="DP Ubuntu Upgrade Mirror Manager" icon="arrow-up-from-bracket" href="https://dpos.xdr.ooo/">
    Ubuntu 24.04 Mirror Server 한 대를 준비하고 Stellar Cyber DP를 Ubuntu 16.04에서 18.04 → 20.04 → 22.04 → 24.04 순으로 업그레이드한 뒤 DP 6.6.0 Phase 2 Bringup까지 수행하도록 구성된 도구입니다. DP는 외부 Artifact Source 대신 Local HTTP Mirror를 사용할 수 있습니다.

    **제품:** `dpos.xdr.ooo`  
    **소스:** `xdr-labs/ubuntu-mirror-automation`
  </Card>

  <Card title="Data Relay Control" icon="arrows-left-right" href="https://control.datarelay.run/">
    **One Stream → Many Routes → Many Destinations** 구조의 Enterprise Data Control Gateway입니다. Stream이 Source 실행과 진행 상태를 관리하고, Route가 Destination별 Transform, 선택적 Protection/Policy 및 Delivery를 담당합니다. Governance, Audit, Quarantine, Replay, Backup 및 운영 Evidence 기능도 제공합니다.

    **제품:** `control.datarelay.run`  
    **소스:** `datarelay-labs/gdc-platform`
  </Card>

  <Card title="Detection Scenario Platform (DSP)" icon="radar" href="https://dsp.xdr.ooo/">
    **XDR/NDR 고객 POC 검증**을 위한 현실적이고 관찰 가능한 Security Activity를 생성하고 Event Store 기반의 구조화된 Evidence와 Report를 만드는 Operational Scenario Runner입니다. 문서화된 검증 범위 안에서 Local 및 Remote Webshell 실행을 지원합니다.

    **제품:** `dsp.xdr.ooo`  
    **소스:** `xdr-labs/xdr-poc-script`
  </Card>
</CardGroup>

## 배포 & Appliance 운영
