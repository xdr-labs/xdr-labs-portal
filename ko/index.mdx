# XDR Labs

**보안 엔지니어링, 인프라 배포, 원격 접속, 플랫폼 업그레이드, 데이터 전달, 탐지 검증을 위한 실전 프로젝트 포털입니다.**

각 프로젝트는 자신의 Source Repository, Release Lifecycle, Documentation, 운영 경계를 독립적으로 유지합니다. 이 사이트는 공통 Directory입니다.

<Tip>
  영문 포털은 [XDR Labs English](/)에서 볼 수 있습니다.
</Tip>
