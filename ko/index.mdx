# XDR Labs

**보안 엔지니어링, 인프라 배포, 원격 접속, 플랫폼 업그레이드, 데이터 전달, 탐지 검증을 위한 실전 프로젝트 통합 포털입니다.**

XDR Labs는 현장에서 반복되는 설치·운영·지원·검증 작업을 줄이기 위해 만든 독립 프로젝트들을 모아둔 중앙 진입점입니다. 각 프로젝트는 자신의 소스 저장소, 릴리스 주기, 문서와 지원 범위를 독립적으로 유지합니다.

<Note>
  모든 프로젝트를 먼저 이해할 필요는 없습니다. 지금 해결하려는 문제를 기준으로 아래 메뉴에서 바로 이동하세요.
</Note>
